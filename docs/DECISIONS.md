## P1 implementation record (2026-11-25)

- Scope: implemented the Glacial Precision visual foundation, reusable layout/UI primitives, shared motion tokens, bilingual routing, translated metadata, language switching, and a development-only review route. No Hero, Floating Dock, animated registry component, portfolio section, Motion dependency, personal introduction, project showcase, or P2 work was added.
- Dependency: installed exact `next-intl@4.16.2`; `package-lock.json` preserved and updated. npm reported two transitive install scripts not yet covered by its `allowScripts` policy (`@parcel/watcher` and `@swc/core`); no approval bypass was applied. Installation, type checking, linting and production build all completed successfully. `npm audit` reports zero vulnerabilities.
- Internationalization architecture: `src/i18n/routing.ts` defines `en` and `vi`, default `en`, always-prefixed URLs and disabled browser/cookie locale detection; `src/i18n/request.ts` validates the locale via `next/root-params` and loads the matching JSON messages; `src/i18n/navigation.ts` exposes locale-aware navigation; `src/proxy.ts` applies current Next.js 16 routing middleware. Shared pages live once under `src/app/[locale]/`; messages are separated into `messages/en.json` and `messages/vi.json`.
- Locale behavior: `/` redirects to `/en`; `/en` and `/vi` render shared components and locale-specific copy; the root layout emits the matching HTML `lang`. The client language switcher keeps the current internal pathname, search string and hash while replacing only the locale. Unsupported `/fr` is rewritten to an English-prefixed unmatched route and returns 404.
- Design tokens: centralized core and semantic colors, primary/secondary/elevated surfaces, muted text, accent, border, focus and interaction states; soft shadow/glow; control/card/panel/pill radii; 4–128 px spacing scale; responsive gutters and section spacing; content/copy widths; press/hover/standard/reveal/stagger durations and the shared `cubic-bezier(.22,1,.36,1)` easing. Tailwind v4 mappings live in `src/app/globals.css`; components reference semantic classes rather than raw colors.
- Typography: Space Grotesk display scale, Be Vietnam Pro body scale and JetBrains Mono metadata scale, each requested with `latin` and `vietnamese` subsets. Responsive display/section headings, body, supporting, caption and metadata styles are shared CSS utilities. Vietnamese review copy with full diacritics is included in the actual preview.
- Layout foundation: `Container` provides content/copy widths and responsive gutters; `Section` provides default/compact vertical rhythm. The design preview demonstrates 4-column mobile, 6-column tablet and 12-column desktop conventions without turning all content into dashboard cards.
- UI primitives: native semantic `Button` (primary/secondary/disabled), `IconButton` with required accessible label, locale-aware `TextLink`, `Badge`, `Surface`, `SectionHeading`, and `Divider`. All controls share hover, focus-visible, active and disabled state tokens; no third-party component library was installed.
- Motion foundation: CSS-only interaction feedback uses shared durations/easing. A global `prefers-reduced-motion: reduce` rule removes smooth scrolling, collapses transitions and suppresses repeated animation. Complex motion and the `motion` package remain deferred to P2.
- Preview behavior: development URLs are `http://localhost:3000/en/design-system` and `http://localhost:3000/vi/design-system`. The pages render the actual tokens, typography, primitives, surfaces, spacing/grid and reduced-motion foundation. They return 404 under `next start` production mode.
- Verified checks: `npm.cmd run typecheck` PASS; `npm.cmd run lint` PASS; final `npm.cmd run build` PASS; `npm.cmd audit` PASS (0 vulnerabilities). The first build exposed a missing Suspense boundary around `useSearchParams`; the shared header was fixed and subsequent builds passed.
- Manual HTTP verification: development server ready on `127.0.0.1:3100`; `/` redirected to `/en`; `/en`, `/vi`, `/en/design-system` and `/vi/design-system` returned 200 with expected localized content; rendered HTML contained `lang=\"en\"` and `lang=\"vi\"`; unsupported `/fr` ended at 404. Production server returned 200 for `/en` and `/vi`, and 404 for both design-system preview URLs.
- Review limitations: no non-Playwright interactive browser tool was available in this environment. Clicking the language switcher, visual comparison at 320/390/768/1024/1440 px, keyboard focus flow and the perceived reduced-motion behavior require Product Owner manual review. Source and HTTP behavior were verified, but these visual/interaction checks are not claimed as complete.

- Git: no commit, push or deployment; existing remote and P0 registry/MCP setup remain unchanged.
