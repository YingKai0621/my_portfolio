Use CSS grid/custom bento for impact and semantic HTML for technical content. shadcn dialogs/tooltips only as needed.

Component access policy (owner-approved, P4): prefer official implementations for free components. If an official component requires paid access that is not authorized, study only its public demo and documentation, then independently reproduce its observable visual and interaction behavior with original code and properly licensed assets. Preserve reference fidelity; do not silently swap in a generic fade/slide or unrelated effect. Never inspect restricted source or bypass licensing. Fey Cards registry source was accessible during P3; its public demo artwork was not copied. Other Labs access remains unverified.

P4 Burn Carousel reference: [Aceternity Burn Carousel](https://ui.aceternity.com/interactions/burn-carousel) is All-Access/Pro, so its source is not installed. Selected Works uses an original Three.js/GLSL noise-driven burn transition on the artwork viewport only, with a luminous irregular edge, configurable duration/color/noise/direction, native project selectors, and static fallback for reduced motion or unavailable WebGL. Project facts, links and technology logos remain outside the shader. This is an independent interpretation of the public demo, not Aceternity source code. The official Apple Cards Carousel stays reserved for future real screenshot galleries.

P4 technology strip references: [Logo Cloud Multiple Rows](https://ui.aceternity.com/blocks/logo-clouds/logo-cloud-multiple-rows) and [Logo Cloud With Swap Animation](https://ui.aceternity.com/blocks/logo-clouds/logo-cloud-with-swap-animation) are All-Access blocks. Their public motion ideas inform an original single-row, pausable CSS marquee plus a project-triggered Motion group swap; no paid source, demo logos, unrelated rotation or automatic project switching is used. Case studies use the existing licensed SVG marks in static responsibility groups.

P5 component selection: the free [Magic UI Icon Cloud](https://magicui.design/docs/components/icon-cloud) registry source was inspected, but its fixed 400px canvas, icon-only output, and extra button/icon dependencies do not meet this section's responsive, named-logo and offscreen-pause requirements as shipped. P5 therefore uses an original lightweight canvas adaptation of its public spherical-icon interaction with already licensed local Devicon SVGs, while the readable names and capability copy remain semantic HTML outside the canvas. The paid [Aceternity Logos With Blur Flip](https://ui.aceternity.com/blocks/logo-clouds/logos-with-blur-flip) informed an earlier user-triggered Motion swap, which the owner subsequently replaced with an always-open inventory; no restricted code was accessed. [Animated Beam](https://magicui.design/docs/components/animated-beam) is deferred because verified system relationships are unavailable; paid Flipping Words is omitted because it would automatically cycle important copy. No new dependency was installed.
