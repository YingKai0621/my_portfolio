# LKD Portfolio

Duy's bilingual personal portfolio, built from the Glacial Precision starter kit. The repository currently contains the P0–P3 foundation, a provisional Hero and an About section awaiting visual review. Start locally with `npm install` and `npm run dev`, then open `/en` or `/vi`. No production deployment is implied.

## Starter kit v1.1 — Glacial Precision

The original kit was a planning package without application code, dependencies, credentials or real image assets. The owner selected Codex, bilingual VIE/ENG and the core colors Black Basalt #0B1013, Bone #E8F3F6 and Glacier Blue #1BA6CD. Remaining design choices are proposed defaults.

## Start (Windows / macOS / Linux)
1. Extract this ZIP. Open the folder containing `AGENTS.md` in Codex (local app, IDE or CLI). If working in an existing repo, merge these docs without overwriting its instructions or configuration.
2. For a fresh extraction outside this repository, initialize Git only if needed (`git init`). Publication requires the owner's explicit request.
3. Copy `prompts/00-kickoff.md` into a new Codex session. This first task is read-only. Review the plan and approve Phase P0 separately.
4. Follow `setup/MCP.md` during P0, not before. If the client cannot run local MCP, use verified registry CLI commands instead.
5. After P0, use `prompts/01-implement-phase.md` and `prompts/02-review-phase.md`. Request one phase at a time; inspect screenshots and tests before approving the next.
